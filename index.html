Seekers per job post, by skill

Visible comments that mention the skill, last three months pooled.

Seeker posts usually list a long “Technologies:” stack, job posts don’t, so most skills sit above the overall line. Compare skills with each other, not with the overall ratio. Matching is one regular expression per skill (skills.py).

Table: every month

All comments counts every top-level comment id Hacker News’ Firebase API lists for the thread, including ones later deleted by their author or marked dead. Visible today counts only the ones you can still read (HN Algolia API). Old threads lose visible comments over the years as people delete them, so the long-run comparison uses all comments. Months younger than 14 days are still open and shown hollow.
